# Open Xprinter для macOS

Открытый USB-драйвер и приложение для печати этикеток на **Xprinter XP-330B**. Один установщик для **Intel и Apple Silicon**, macOS 14 и новее. Лицензия MIT; закрытые файлы Xprinter не входят в пакет.

[Скачать установщик](https://github.com/ismoil-nosr/xprinter-macos/releases/latest) · [English](../README.md) · [简体中文](README.zh-CN.md) · [Переводы и участие](TRANSLATING.md)

## Установка

1. Скачайте `.pkg` из Releases и откройте его. Текущая версия не подписана Developer ID и не проверена сервисом нотарификации Apple. Если macOS блокирует файл, откройте **Настройки системы → Конфиденциальность и безопасность → Всё равно открыть** именно для этого установщика. При отдельной блокировке приложения подтвердите его тем же способом. Отключать защиту macOS не требуется.
2. Установите пакет, подключите XP-330B по USB, включите принтер и загрузите термоэтикетки. Принтер должен работать в режиме этикеток TSPL.
3. Откройте **Open Xprinter** в «Программах». В меню справа вверху выберите **Русский** (или **English**, **简体中文**, **Как в системе**). При необходимости нажмите **Настроить принтер** и подтвердите обычный запрос пароля администратора macOS.
4. Выберите размер рулона, тип бумаги и высоту зазора. **58 × 40 мм** — это 58 мм поперёк головки и 40 мм по направлению подачи. Зазор измеряется отдельно; начальные 2 мм подходят не каждому рулону.
5. Нажмите **Сохранить для других приложений…**, чтобы сохранить эти параметры для Chrome, Preview и других программ.
6. Напечатайте одну этикетку. Убедитесь, что весь код и текст остались на ней, и проверьте сканирование перед массовой печатью.

В других программах выбирайте **Xprinter XP-330B Labels (Open Source)**, нужный размер бумаги и одну страницу на лист. Для PDF этикетки подходящего размера сохраняйте её физический размер; для отличающегося размера используйте подгонку с проверкой читаемости кода.

Интерфейс, меню, помощь и ошибки приложения переведены на русский, английский и упрощённый китайский. Переключение языка действует сразу и сохраняется при следующем запуске; текст этикетки, импортированный файл, размер, бумага и зазор не меняются. Системные окна авторизации и часть элементов выбора файлов используют язык macOS. В режиме «Как в системе» приложение выбирает первый поддерживаемый язык macOS, а при отсутствии совпадения — английский.

## Что исправлено

Драйвер сохраняет правильную ширину и длину подачи в macOS. Перед первым изображением он задаёт размер и зазор, затем отправляет `HOME`: принтер находит начало этикетки. На непрерывном рулоне эта команда не отправляется. Это устраняет случай, когда корректное изображение начинается посередине этикетки и пересекает зазор.

При смене USB-порта нажмите **Установить / восстановить USB-драйвер**. При смене рулона сохраните новые размеры. **Выровнять начало этикетки…** выполняет отдельное выравнивание начала этикетки; драйвер также делает это автоматически перед каждым заданием.

Программа создаёт Code 128 и QR, поддерживает Unicode-текст, PDF, картинки и CSV. Код рисуется по точкам принтера при 203 dpi; слишком плотные штрихкоды отклоняются. Примеры CSV лежат в [examples](../examples).

Code 128 допускает печатные символы ASCII; для кириллицы и китайского текста используйте QR или текстовую этикетку. Заголовки CSV (`code`, `title`, `footer`, `type`, `quantity`) и значения `code128`, `qr`, `text` сохраняются на английском независимо от языка интерфейса. Сообщения об ошибках, Pull Request и улучшения перевода можно присылать на русском; порядок описан в [CONTRIBUTING.md](../CONTRIBUTING.md) и [руководстве по переводам](TRANSLATING.md).

## AI и MCP

Отдельный открытый [MCP-сервер](https://github.com/ismoil-nosr/xprinter-mcp) позволяет AI-клиентам на macOS, Windows и Linux создавать этикетки, смотреть превью, отправлять печать и проверять свои задания. Локально используется stdio, удалённо — SSH или HTTPS с авторизацией. Сервер работает на Mac с подключённым USB-принтером.

Нужны Open Xprinter **0.3.0+** и Node 24+ на серверном Mac. MCP устанавливается отдельно; обычный установщик драйвера не открывает сетевых портов и не требует Node. [Инструкция на русском](https://github.com/ismoil-nosr/xprinter-mcp/blob/main/docs/README.ru.md).

## Ограничения

Проект независимый и не является официальным продуктом Xprinter. Версия 0.3.0 рассчитана на XP-330B с USB; другие модели, Bluetooth и Ethernet не заявлены. Ширина печати — до 76 мм. Этикетка 4×6 дюймов шире головки этого принтера. Чёрные метки и другие рулоны требуют проверки на вашем устройстве; подробности в [результатах проверки](VALIDATION.md).

Если этикетки пропускаются, проверьте размер, зазор, режим принтера и расположение/чистоту датчика. Установщик сохраняет существующие очереди и принтер по умолчанию. Не отключайте Gatekeeper или SIP.

Удаление после завершения заданий:

```sh
sudo /Library/Printers/OpenXprinter/uninstall.sh
```

С `--dry-run` можно посмотреть план удаления. Другие принтеры и ваши документы сохраняются. Сообщения об ошибках и результаты проверки оборудования принимаются через [GitHub Issues](https://github.com/ismoil-nosr/xprinter-macos/issues).

## Безопасность

[Политика безопасности и приватное сообщение об уязвимости](../SECURITY.md). CSV: до 4 МиБ, 16 столбцов, 4 096 байт UTF-8 на поле и 500 этикеток с учётом количества. Версия 0.3.1 сразу отклоняет превышение лимитов. Генератор MCP завершается по собственному таймеру через 25 секунд; требуется обновление для MCP 0.2.1. Устанавливайте обновления macOS: системные PDF/image/CUPS библиотеки обновляет Apple. Пакет пока без подписи Apple и нотариализации.
